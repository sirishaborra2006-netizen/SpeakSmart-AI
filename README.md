SpeakSmart AI 🎤

An AI-powered public speaking coach built with Python and Streamlit to help users improve their speaking skills through speech analysis and personalized feedback.

🚀 Features

- Audio Input: Upload or record speech for analysis.
- Speech Transcription: Convert speech audio into text using OpenAI Whisper.
- Filler Word Detection: Identify common filler words such as "um", "uh", "actually", and "basically".
- Speaking Metrics: Calculate total words, speech duration, words per minute (WPM), and filler word statistics.
- Confidence Score: Estimate speaking performance using speech-related metrics.
- AI-Based Suggestions: Get recommendations to improve speaking pace, fluency, and vocabulary.
- Practice Questions: Practice interview, group discussion, self-introduction, and public speaking questions.
- Visual Analytics: View charts showing filler words, word distribution, and speaking performance.
- PDF Reports: Generate downloadable reports containing analysis results and feedback.

🛠️ Tech Stack

- Python
- Streamlit
- OpenAI Whisper
- Pandas
- Matplotlib
- Plotly
- ReportLab

⚙️ Installation and Setup

1. Clone this repository:
   
   git clone https://github.com/sirishaborra2006-netizen/SpeakSmart-AI.git

2. Open the project folder:
   
   cd SpeakSmart-AI

3. Create and activate a Python virtual environment if needed.

4. Install the required dependencies:
   
   pip install -r requirements.txt

5. Run the application:
   
   streamlit run app_backup.py
